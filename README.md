# web-motion-kit-8000

Правила, навыки, промты и проверки для Claude Code: сайты бизнеса с продуманным движением, истории по прокрутке, 3D в браузере, интерактивные карты и браузерные игры. Собраны 17.11.2026 из открытых навыков и разборов (`reference/sources.md`). Ни один наш проект по ним ещё не прошёл, первый проект каждого типа дописывает уроки.

Ролики (реклама, объяснялки, эссе) живут в соседнем репозитории `clip-maker-8000`. Ролик про сайт делается там, сам сайт здесь.

## Как пользоваться за минуту

1. Открой Claude Code в этой папке или скопируй её содержимое (CLAUDE.md, `.claude/`, `prompts/`, `reference/`, `tools/`) в рабочий каталог. Проекты Claude Code создаёт в `projects/<имя>/`, эта папка в git не попадает.
2. Скажи по-человечески, что нужно: «сделай сайт для салона», «сделай сайт-кино про кроссовки», «сделай 3D-тур по квартире», «сделай карту наших точек», «сделай мини-игру для акции». Навык `web-router` выберет тип.
3. На каждой остановке Claude Code показывает результат и ждёт «да». Проверяй по `prompts/review_checklist.md`.

## Какой проект, какой маршрут

| Что просишь | Тип | Навык | Первый промт | Носитель по умолчанию |
|---|---|---|---|---|
| сайт бизнеса: магазин, салон, кафе, услуги | сайт | `web-site` | `prompts/site/00_start.md` | настоящие фото и данные, один момент движения |
| сайт-кино, «как у Apple» | история по прокрутке | `web-scroll-story` | `prompts/scroll-story/00_start.md` | кадры по прокрутке, 3D-мир или типографика |
| 3D-объект, конфигуратор, тур, мир | 3D-сцена | `web-3d-scene` | `prompts/3d-scene/00_start.md` | React Three Fiber или three.js |
| карта, город, глобус | карта | `web-map` | `prompts/map/00_start.md` | MapLibre, для 3D-города Cesium |
| мини-игра, игровой интерактив | игра | `web-game` | `prompts/game/00_start.md` | three.js или R3F, Rapier |

Остановки по типам в таблице `CLAUDE.md`, раздел «Порядок работы». Выкладка только по прямому «да».

## Какую модель брать

- Opus: старт, направление, первый экран, 3D-мир, полная сборка.
- Sonnet: точечные правки, скрипты, проверки.

## Что держать в голове

- Сначала тип, потом всё остальное. Вид бизнеса решает, нужны ли эффекты.
- Всё содержание настоящее. Фото товаров с отчётом до сборки. Контакты только подтверждённые.
- Первый экран утверждается статично до движения.
- Проверка только в настоящем браузере на 390, 768, 1024, 1440.
- Оценку «слабо, нормально, сильно» ставит свежий субагент и человек.
- Репозиторий публичный: без данных клиентов, ключей, личных путей и чужих брендов.
