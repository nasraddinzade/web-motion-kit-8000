# Роутер. Какой это проект

## Шаг 1. Определи тип

| Признаки в запросе | Тип | Навык |
|---|---|---|
| сайт бизнеса, магазин, салон, кафе, клиника, услуги, компания, портфолио, запись, корзина | сайт | `web-site` |
| сайт-кино, «как у Apple», продукт собирается или раскрывается при прокрутке, история по главам, видео по прокрутке | история по прокрутке | `web-scroll-story` |
| 3D-объект, 3D-мир, конфигуратор, 3D-тур по дому или помещению, мир, по которому ведёт прокрутка | 3D-сцена | `web-3d-scene` |
| карта, город, район, маршрут, глобус, точки на карте, интерактивная площадка на местности | карта | `web-map` |
| игра, мини-игра, игровой интерактив, управление персонажем, очки | игра | `web-game` |

Если подходят два, реши по главному действию посетителя: купить или записаться (сайт), понять историю (история), рассмотреть предмет или место (3D), найти место (карта), играть (игра). Сайт бизнеса с одной 3D-секцией остаётся сайтом: 3D-секцию делай по `web-3d-scene`, всё остальное по `web-site`.

Если всё ещё два варианта, задай один вопрос выбором (`AskUserQuestion`, варианты типов). Если спросить нельзя, возьми самый вероятный и напиши, почему.

## Шаг 2. Одна строка человеку

«Это [тип], потому что [причина]. Работаю по навыку [имя], первая остановка [какая].»

Если нет обязательного (ссылка на бизнес или его материалы, кто посетитель, одно главное действие, устройства), первая остановка это интервью выбором по `reference/interview.md`. Промт `00_start.md` с пустыми полями не запускай.

## Шаг 3. Иди по маршруту типа

| Общий навык | Когда |
|---|---|
| `web-brief` | всегда, до кода |
| `web-art-direction` | всегда: вид бизнеса, направление, первый экран, проверка на шаблонность |
| `web-assets` | фото, сгенерированные картинки и видео, 3D-модели, последовательности кадров |
| `web-motion` | любое движение: GSAP, прокрутка, Lenis, отключение анимации, очистка |
| `web-qa` | перед каждым показом: браузер, ширины, путь посетителя, производительность, свежий взгляд |

## Шаг 4. Справочники

- `reference/stack.md` какой стек под какой тип.
- `reference/slop-patterns.md` признаки шаблонного сайта.
- `reference/perf-budget.md` бюджеты веса и кадров.
- `reference/scroll-sequence.md` видео и кадры по прокрутке.
- `reference/three-world.md` 3D: мир, камера, материалы, проверки.
- `reference/maps.md` карты, тайлы, условия.
- `reference/deploy.md` выкладка, домен, ключи, кэш.
- `reference/sources.md` откуда это всё и под какой лицензией.

## Что общее у всех типов

Настоящее содержание, родная обратимая прокрутка, первый экран без JavaScript, отключение анимации по системной настройке, проверка в браузере на четырёх ширинах, честный отчёт. Подробно в `CLAUDE.md`.
