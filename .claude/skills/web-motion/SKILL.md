# Движение

Основание: официальные навыки GSAP, cinematic-scroll-storytelling, build-awwwards-quality-sites, optimize-web-animations, no-ai-design-slop. Если в проекте стоят официальные навыки GSAP (`npx skills add https://github.com/greensock/gsap-skills`), API бери оттуда, здесь правила вкуса и порядка.

## Движение объясняет

Движение показывает состояние, причину, порядок, связь или перемещение в пространстве. Если оно ничего не объясняет, убери. Одна оркестрованная сцена (загрузка или раскрытие) сильнее россыпи эффектов.

## Система

- GSAP главный движок. CSS для простых ховеров, фокуса и нажатий.
- Один движок плавной прокрутки на сайт: Lenis или никакого. Никогда два. Подключи его к ScrollTrigger, пересчитай после загрузки медиа и шрифтов.
- Одно свойство двигает одна система.
- ScrollTrigger только для оправданных закреплений и прокрутки по кадрам. Обычные секции появляются один раз.

## Числа (ориентир, правь под проект)

| Что | Значение |
|---|---|
| выход появления | `power3.out` или `power4.out` |
| сцены по прокрутке | `ease: "none"`; для кадров по прокрутке сначала `scrub: true`, число 0,8–1,4 только после проверки обратимости |
| появление текста | 0,8–1,1 с |
| шаг по словам | 0,035–0,07 с для заголовков; 0,04–0,09 с для заголовков глав в 3D и истории |
| шаг по строкам | 0,08–0,14 с |
| шаг карточек | 0,06–0,1 с |
| сдвиг появления | 24–48 px |
| размытие | 4–10 px → 0 |
| глубина стопки карточек | масштаб 1 → 0,92 |

Для сайтов-историй без пружин и упругих отскоков. Для игр и интерфейсов пружины уместны.

## Текст по словам

Держи одну нетронутую доступную копию текста. Разбивай только текстовые узлы, ссылки и выделения не ломай. Разбиение по строкам запрещено: перенос строк меняется с шириной, шрифтом, масштабом. Сгенерированные слова скрывай от чтения с экрана, если есть целая копия.

## Обязательно

- `prefers-reduced-motion: reduce`: без плавной прокрутки и закреплений, конечные состояния сразу, а не укороченная анимация.
- Первый экран полный без JavaScript.
- Анимируй transform и opacity. `will-change` только на то, что анимируется.
- Касание и клавиатура работают так же, как курсор. Эффекты от курсора добавочные.

## Остановка вне экрана и очистка

- CSS-анимации, бегущие строки, мерцающие заглушки вне экрана на паузе (IntersectionObserver и класс).
- Циклы requestAnimationFrame, canvas, WebGL, физика стартуют при появлении и останавливаются при уходе.
- При уходе со страницы: убить твины и ScrollTrigger, отключить наблюдатели, снять слушатели тем же обработчиком, отменить кадры и таймеры, освободить геометрии, материалы, текстуры, рендерер, остановить медиа. Асинхронные загрузчики проверяют флаг «уже ушли».

## Как не надо

- Перехват колеса.
- Пружины и отскоки на сайте-истории, резкие скачки масштаба, «игровые» вспышки.
- Слишком много эффектов прокрутки одновременно.
- Карусели по таймеру, наклоны по курсору.
- Lenis и Locomotive вместе.
