# Движение

Основание: официальные навыки GSAP, cinematic-scroll-storytelling, build-awwwards-quality-sites, optimize-web-animations, no-ai-design-slop. Если в проекте стоят официальные навыки GSAP (`npx skills add https://github.com/greensock/gsap-skills`), API бери оттуда, здесь правила вкуса и порядка.

## Движение объясняет

Движение показывает состояние, причину, порядок, связь или перемещение в пространстве. Если оно ничего не объясняет, убери. Одна оркестрованная сцена (загрузка или раскрытие) сильнее россыпи эффектов.

## Движение интерфейса

Кнопки, корзина, меню, формы, всплывающие окна: решения, кривые, длительности, хореография группы и формат замечаний в `reference/motion-ui.md` (по навыкам Эмиля Ковальского). Перед кодом ответь, двигать ли вообще (частота) и зачем (одно слово цели). Для группы элементов сначала таблица ролей (главный, поддержка, украшение, неподвижное).

## Настоящий продукт в движении

Для вида «техника и софт» (`web-site`). Урок SOS в `reference/lessons.md`.

- Есть исходник продукта, открой компонент до кода сайта. Размеры, тайминги, кривые и состояния (покой, нажатие, процесс, готово) бери оттуда. Накладка поверх скриншота, которая «примерно похожа», не годится: человек сразу видит, что это не как в приложении.
- Приём: на скриншоте элемент закрашен фоном, живой компонент стоит поверх в тех же координатах, в единицах ширины телефона (`cqw`). У `cqw` на самом элементе отсчёт от ближайшего предка-контейнера, поэтому у каждой обёртки телефона `container-type: inline-size` и ширина, равная ширине телефона (обёртка шириной в колонку дала толстый корпус и экран, который «не вписывается»).
- Анимирует продукт не transform (обводка по краю через `stroke-dashoffset`), повторяй как в продукте на маленьком SVG и запиши исключение в `review_log.md`.
- Переходы между экранами продукта как в его платформе: на iOS новый экран въезжает с края, старый уходит на треть и темнеет. По прокрутке, обратимо, в RTL с другой стороны.
- Длительности продукта главнее таблицы `reference/motion-ui.md`: 300 мс там для интерфейса самого сайта.
- Экраны, которые ездят внутри скруглённого стекла, обрезай `clip-path: inset(0 round …)` на отдельной обёртке. Видеокарта выносит движущийся слой, и `overflow: hidden` со скруглением его углы не держит (в браузере без видеокарты всё выглядит верно).

## Система

- GSAP главный движок. CSS для простых ховеров, фокуса и нажатий.
- Один движок плавной прокрутки на сайт: Lenis или никакого. Никогда два. Подключи его к ScrollTrigger, пересчитай после загрузки медиа и шрифтов.
- Одно свойство двигает одна система.
- ScrollTrigger только для оправданных закреплений и прокрутки по кадрам. Обычные секции появляются один раз.

## Числа (ориентир, правь под проект)

| Что | Значение |
|---|---|
| выход появления | `power3.out` или `power4.out` |
| сцены по прокрутке | `ease: "none"`; для кадров по прокрутке сначала `scrub: true`, число 0,8–1,4 только после проверки обратимости |
| появление текста | 0,8–1,1 с |
| шаг по словам | 0,035–0,07 с для заголовков; 0,04–0,09 с для заголовков глав в 3D и истории |
| шаг по строкам | 0,08–0,14 с |
| шаг карточек | 0,06–0,1 с |
| сдвиг появления | 24–48 px |
| размытие | 4–10 px → 0 |
| глубина стопки карточек | масштаб 1 → 0,92 |

Для сайтов-историй без пружин и упругих отскоков. Для игр и интерфейсов пружины уместны.

## Текст по словам

Держи одну нетронутую доступную копию текста. Разбивай только текстовые узлы, ссылки и выделения не ломай. Разбиение по строкам запрещено: перенос строк меняется с шириной, шрифтом, масштабом. Сгенерированные слова скрывай от чтения с экрана, если есть целая копия.

## Обязательно

- `prefers-reduced-motion: reduce`: без плавной прокрутки, закреплений, перемещений, масштаба и параллакса. Короткое растворение по прозрачности до 200 мс остаётся, где помогает понять смену состояния (`reference/motion-ui.md`, раздел 6).
- Первый экран полный без JavaScript.
- Анимируй transform и opacity. `will-change` только на то, что анимируется.
- Стартовое положение, заданное в CSS через `transform`, GSAP прочитает как `x`/`y` и прибавит к `xPercent`: элемент встанет на полпути. Задаёшь старт в CSS, при запуске сбрасывай явно (`gsap.set(el, { x: 0, xPercent: 100 })`).
- Тень у движущегося или закреплённого элемента не `box-shadow` и не `filter: drop-shadow` (выходят пятном с резким краем), а нарисованная: радиальные градиенты, которые гаснут раньше своей границы. Родитель не режет её `overflow: hidden`; если нужно, только по горизонтали `overflow-x: clip`, и проверь ширины 1024–1100, где свечение у края расширяет страницу.
- Касание и клавиатура работают так же, как курсор. Эффекты от курсора добавочные.
- Главный момент есть на 390, а не только на компьютере. Липкая сцена, сделанная только для широких экранов, оставляет телефон без движения.
- Нажимаемое показывает себя: на первом экране 390 движение в покое (дыхание, пульс) и короткая подпись. Без этого посетитель не поймёт, что элемент живой.
- Ловушки ScrollTrigger на телефоне (документация и форум GSAP). У картинок и видео выше любого триггера заданы ширина и высота или `aspect-ratio`: без размеров они грузятся с нулевой высотой, и все позиции триггеров ниже съезжают. Если раскладка меняется после загрузки (шрифты, картинки, раскрытый блок), вызови `ScrollTrigger.refresh()` один раз после этого. Свой `resize` с `refresh()` не вешай: ScrollTrigger сам пересчитывает с задержкой, лишние пересчёты дают скачки. Адресная строка телефона: `ScrollTrigger.config({ ignoreMobileResize: true })` и высоты в `svh` (`web-scroll-story`).

## Остановка вне экрана и очистка

- CSS-анимации, бегущие строки, мерцающие заглушки вне экрана на паузе (IntersectionObserver и класс).
- Циклы requestAnimationFrame, canvas, WebGL, физика стартуют при появлении и останавливаются при уходе.
- При уходе со страницы: убить твины и ScrollTrigger, отключить наблюдатели, снять слушатели тем же обработчиком, отменить кадры и таймеры, освободить геометрии, материалы, текстуры, рендерер, остановить медиа. Асинхронные загрузчики проверяют флаг «уже ушли».

## Как не надо

- Перехват колеса.
- Пружины и отскоки на сайте-истории, резкие скачки масштаба, «игровые» вспышки.
- Слишком много эффектов прокрутки одновременно.
- Карусели по таймеру, наклоны по курсору.
- Lenis и Locomotive вместе.
