# Проверка и отчёт

Сборка, линтер и чтение кода не доказывают, что страница работает. Доказывает только настоящий браузер.

## Обязательные проверки

| Проверка | Как | Критерий |
|---|---|---|
| Ширины | скриншоты 390, 768, 1024, 1440 | нет горизонтальной прокрутки, обрезанных кнопок, наложений, пустых мест |
| Путь посетителя | тапы и клики по настоящим элементам до результата, без прямых адресов | результат достигнут на 390 и 1440 |
| Помехи | пустые поля, длинные русские и узбекские строки, медленная сеть, возврат назад, обрыв посередине | понятное сообщение, ничего не ломается |
| Прокрутка | медленно вперёд и назад, рывок, перетаскивание полосы, перезагрузка в середине, смена размера | одна позиция даёт одно состояние, нет прыжков и вспышек |
| Без анимации | `prefers-reduced-motion` | конечные состояния, без закреплений |
| Без JavaScript | первый экран | полный и понятный |
| Производительность | замер по `reference/perf-budget.md` на 390 с замедлением процессора | в бюджете |
| Память | 10 минут простоя и три перехода по страницам | не растёт |
| Консоль | все страницы | без ошибок |
| Доступность | клавиатура, фокус, контраст, подписи к картинкам | всё достижимо, контраст текста не ниже 4,5:1 |
| Данные | контакты, цены, адрес против подтверждённого списка | совпадает |

Каждую новую проверку сначала прогони на заведомо плохом входе.

## Цикл правки

- Смотри в трёх масштабах: вся страница, экран, кроп детали в 100 %.
- Оценки себе 1–10: первый экран, читаемость на телефоне, движение, разнообразие, композиция, верность бренду и данным, производительность. Чини три худших, пиши строку в `review_log.md`. Не меньше трёх кругов для нового проекта. Если два круга подряд не подняли самую низкую оценку, остановись и доложи.
- После двух-трёх кругов четыре критика параллельно по скриншотам: композиция, текст и читаемость, путь и понятность, верность бренду и настоящему содержанию.

## Свежий взгляд

Перед показом полного результата запусти субагента, который не видел твоих правок. Дай скриншоты, видео экрана, бриф. Попроси найти то, что заказчик попросит переделать, и оценить «слабо, нормально, сильно». Его ответ в отчёт без смягчений. Твоя собственная оценка не считается.

## Формат отчёта

1. Тип, навык, остановка.
2. Что сделано, одной-двумя строками.
3. Таблица проверок: проверка, результат, критерий.
4. **НЕ прошло** отдельным разделом.
5. Не проверено мной: что требует глаз, ушей, настоящих устройств.
6. Ответ свежего субагента без правок.
7. Отличия от плана.

## Запреты

- «Исправлено» без скриншота до и после.
- «Быстро» без замера.
- «Работает на телефоне» без проверки на 390 и замедления.
- Скрытые провалы.
