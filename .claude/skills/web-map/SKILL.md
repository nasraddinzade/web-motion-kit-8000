# Карта, город, глобус

Статус: собран по официальным навыкам MapLibre, правилам Google Map Tiles и чужим навыкам (globe-gl, Cesium, геовизуализация). На наших проектах не проверен.

## Выбери движок

| Нужно | Движок | Заметка |
|---|---|---|
| обычная интерактивная карта, точки, районы, маршрут | MapLibre GL JS | данные не включены: нужен стиль и источники тайлов |
| свои тайлы без сервера | MapLibre + PMTiles | файл на статическом хостинге |
| рельеф и холмы | MapLibre, raster-dem | без отдельной подложки |
| много данных: дуги, потоки, тепловые карты, тысячи точек | deck.gl поверх MapLibre | GPU-слои |
| фотореальный 3D-город | CesiumJS или 3d-tiles-renderer с Google Photorealistic 3D Tiles | платно, строгие условия, ниже |
| глобус с данными | globe.gl | точки, дуги, полигоны, подписи |

## Условия и лицензии (до кода)

- Подложка и тайлы имеют свои условия. Запиши провайдера, условия и атрибуцию в `CREDITS.md` до первой строки кода.
- Google Map Tiles: нельзя заранее скачивать, индексировать, хранить или кэшировать контент, кроме разрешённых случаев. Нельзя использовать для анализа изображения и распознавания объектов. Логотип Google и строки атрибуции данных обязательны и меняются по мере движения. Измерять высоты и расстояния по 3D-изображению программно нельзя.
- Значит видео пролёта над фотореальным городом для рекламы требует отдельной проверки условий. Не обещай его заказчику без этого.
- OpenStreetMap: атрибуция обязательна.

## Картография

- Подписи читаются на любой подложке: цвет текста и ореол подбираются под тип подложки (вектор или спутник).
- Свои слои вставляй под подписи подложки, не поверх.
- Точка интереса отделяется от фона силуэтом и контрастом, а не только цветом.
- На спутниковой подложке дороги и линии тоньше и спокойнее, чем на векторной.
- Проверка контраста подписей как у текста.

## Движение на карте

- Пролёт камеры (flyTo) с понятной целью и длительностью по расстоянию, не одинаковый для всех.
- Маршрут рисуется по ходу прокрутки или по кнопке, обратимо.
- Пользователь всегда может взять управление. Касание не застревает в карте: прокрутка страницы на телефоне не должна попадать в ловушку карты.

## Для бизнеса

Для сайта места карта это «как прийти»: адрес, кнопка маршрута в приложении карт, часы. Подтверждённый адрес (`CLAUDE.md`). Сложная 3D-карта для кафе обычно лишняя.

## Как не надо

- Карта без атрибуции или с атрибуцией, закрытой своими кнопками.
- Скачанные и сохранённые тайлы Google.
- Карта во весь экран телефона, из которой нельзя прокрутить страницу.
- Тысячи DOM-маркеров вместо GPU-слоя.

## Приёмка

`web-qa` плюс: атрибуция видна на всех ширинах и в каждом состоянии камеры; подписи читаются на 390; страница прокручивается мимо карты пальцем; карта не грузит тайлы, пока не видна; запасной вариант при отказе WebGL (статичная картинка и ссылка на карты).
