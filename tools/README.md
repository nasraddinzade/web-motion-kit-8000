# Скрипты

Зависимости: Python 3.10+, ffmpeg в PATH (путь можно задать переменной `FFMPEG`). Запускай из корня репозитория или проекта, пути передавай аргументами.

| Скрипт | Что делает | Запуск |
|---|---|---|
| `frames.py` | видео → кадры WebP для прокрутки по кадрам, `manifest.json` с весом, лист кадров | `python tools/frames.py видео.mp4 --out frames/desktop --width 1600 --fps 30` · `--selftest` |
| `check_repo.py` | проверка самого репозитория правил: навыки и скрипты в индексах, битые ссылки, маркеры слияния, повторные номера, похожие на ключи строки | `python tools/check_repo.py` |

Чего скрипты не делают: не проверяют вкус, производительность в браузере и путь посетителя. Это `web-qa` в настоящем браузере. Проверки конкретного проекта (Playwright, замеры) пишутся в проекте, каждую сначала прогоняй на заведомо плохом входе.
