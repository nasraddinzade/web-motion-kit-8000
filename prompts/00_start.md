# С чего начать

Скажи Claude Code по-человечески, что нужно. Роутер `web-router` сам выберет тип. Если хочешь стартовать вручную, возьми промт типа:

| Что нужно | Промт |
|---|---|
| сайт для бизнеса | `prompts/site/00_start.md` |
| история по прокрутке, сайт-кино | `prompts/scroll-story/00_start.md` |
| 3D-объект, тур, мир | `prompts/3d-scene/00_start.md` |
| карта, город, глобус | `prompts/map/00_start.md` |
| игра | `prompts/game/00_start.md` |

Модель. Старт, направление, первый экран, 3D-мир, полная сборка на Opus. Точечные правки, скрипты, проверки на Sonnet.
