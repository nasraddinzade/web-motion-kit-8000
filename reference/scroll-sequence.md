# Видео и кадры по прокрутке

Основание: scroll-scrubbed-visual-sequence (MengTo, MIT), разборы «как у Apple» (`reference/sources.md`). Не проверено в нашем проекте.

## Конвейер

1. Ключевые кадры предмета (начало, середина, конец), одинаковые по форме, цвету, свету, надписям.
2. Видео между ключевыми кадрами (генерация или съёмка, с разрешения и бюджетом).
3. `python tools/frames.py видео.mp4 --out frames --width 1600 --fps 30` и отдельно для телефона `--width 900`. Скрипт пишет WebP, `manifest.json` с числом кадров и весом, лист кадров.
4. Сайт: секция высотой из бюджета прокрутки, липкая сцена, canvas, кадр по прогрессу.

## Описать до кода

```js
const sequence = {
  scrollVh: 280,          // длина в высотах экрана
  frameCount: 96,
  fit: "contain",
  posterFrame: 0,
  reducedMotionFrame: 95, // что показать без анимации
  copyStops: [0, 0.42, 0.78]
};
```

Прогресс: `(верх окна − верх секции) / (высота секции − высота окна)`, обрезанный в 0–1. Источник правды только позиция прокрутки.

## Какой носитель

- **Видео:** непрерывное, фотографическое. Частые ключевые кадры при кодировании, `currentTime` писать не чаще раза в кадр.
- **Кадры:** когда важен точный кадр. Сначала текущий и соседние, всё остальное потом.
- **Canvas:** процедурное рисование. Плотность пикселей не выше 2, перерисовка только при смене прогресса.
- **SVG и DOM:** схемы, карточки, интерфейс, доступный текст.
- **WebGL:** только если глубина, свет или настоящая камера усиливают идею. Постер обязателен.

## Обязательно

- Постер виден, пока не нарисован первый настоящий кадр.
- Номер кадра обрезан в 0…frameCount−1.
- Устаревшие запросы отменяются, при быстрой прокрутке не ставь в очередь каждый кадр.
- Фокусная точка задана, предмет не обрезается на телефоне.
- Вне экрана и в скрытой вкладке ничего не декодируется и не рисуется.
- Без анимации: без закрепления, один выбранный кадр, обычный поток.

## Проверка

Вперёд и назад, рывок, смена размера внутри секции, ширины 390, 768, 1024, 1440, незагруженные кадры, заблокированное видео, без анимации, клавиатура, уход со страницы, консоль.
