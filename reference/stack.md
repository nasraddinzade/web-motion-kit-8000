# Какой стек под какой тип

Статус: «док.» значит прочитано в документации или чужом навыке, «опыт» значит проверено в нашем проекте. Опыта пока нет.

| Тип | Основа | Движение | Когда другое | Статус |
|---|---|---|---|---|
| сайт | Next.js или Astro, Tailwind или свой CSS | GSAP для моментов, CSS для ховеров | простая визитка: чистый HTML | док. |
| история по прокрутке | тот же сайт | GSAP ScrollTrigger, canvas с кадрами или видео, Lenis по желанию | короткая простая сцена: CSS scroll-timeline | док. |
| 3D-сцена | React Three Fiber + drei (в React-проекте) или three.js | useFrame, GSAP для таймлайнов камеры, @react-three/postprocessing | не React: чистый three.js | док. |
| карта | MapLibre GL JS, PMTiles | flyTo, слои | много данных: deck.gl; фотореальный город: CesiumJS или 3d-tiles-renderer; глобус: globe.gl | док. |
| игра | three.js или R3F, Rapier | свой цикл с фиксированным шагом физики | 2D: canvas или PixiJS | док. |

## Стартовый выбор

- Магазин или визитка без своего сервера, корзина в localStorage и заказ в мессенджер: Astro.
- Нужен React для R3F, сложный интерфейс или свой сервер: Next.js.
- Playwright для проверок ставить можно (официальный пакет).

## Официальные навыки, которые можно ставить

- GSAP: `npx skills add https://github.com/greensock/gsap-skills` (MIT, от авторов GSAP). Ядро, таймлайн, ScrollTrigger, React, производительность.
- MapLibre: `npx skills add maplibre/maplibre-agent-skills` (MIT, организация MapLibre). Источники тайлов, PMTiles, рельеф, картография.
- Remotion, если из сайта делается ролик: в репозитории `clip-maker-8000`.

## Только с согласия человека (не официальные, MIT)

- `cloudai-x/threejs-skills`: three.js r186, R3F 9.8, drei 10.7, gltf-transform 4.5. Основы, шейдеры, постобработка, производительность, сжатие моделей.
- `emalorenzo/three-agent-skills`: 70+ правил R3F по важности.
- `MengTo/Skills`: история по прокрутке, мир по прокрутке, кадры по прокрутке, тур, оптимизация анимаций, проверка на шаблонность.
- `majidmanzarpour/threejs-game-skills`: игры, режиссёр и специалисты.

Правило из `CLAUDE.md`: чужие навыки и код не ставим и не запускаем без согласия. Идеи из них уже перенесены в наши навыки.

## Версии

Закрепляй версии. Three.js меняет API между выпусками (с r160 только ES-модули). Перед обновлением мажорной версии читай заметки о выпуске.
